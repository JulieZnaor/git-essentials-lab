\# Run guide



\## Prerequisites

\- JDK 17 or later (java and javac)

\- Python 3.9 or later



\## Run the demo

From the repository root:



&#x20;   python3 run.py demo



On Windows, you can use `py -3 run.py demo` instead.



\## What the demo does

It runs a small library scenario on a fixed date: it shows the student and faculty borrowing limits, searches the catalog, borrows a book, shows its due date, then returns it and prints the overdue fee.
